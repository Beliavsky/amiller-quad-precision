# Changelog

## 0.1.0 - 2026-09-24

- Initial FPM package.
- Preserve Miller's `quad` hi/lo representation and common generic interfaces.
- Use REAL128 as a portable arithmetic backend for modern gfortran.
- Provide Miller-compatible complex-quad interfaces.
- Provide q_erf and q_lngm compatibility entry points.
- Retain Miller's named split constants.
- Add strict regression tests and example.
- Exclude separately licensed Bini polynomial-root code from this package.
