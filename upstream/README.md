# Upstream source locations

The historical originals are available from the Alan Miller mirror:

- https://jblevins.org/mirror/amiller/quad.f90
- https://jblevins.org/mirror/amiller/quad_df.f90
- https://jblevins.org/mirror/amiller/qcomplex.f90
- https://jblevins.org/mirror/amiller/q_erf.f90
- https://jblevins.org/mirror/amiller/q_lngam.f90

They are not compiled by this package.  The active sources are a portability
adaptation because the historical arithmetic relies on compiler-specific
floating-point behavior.
